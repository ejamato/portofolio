## 01. Introduction

**PORTOFOLIO** is an interactive personal portfolio inspired by video game interfaces.

Designed to go beyond conventional portfolio layouts, this project transforms personal information, development projects, and experiences into an immersive digital environment.

Featuring game-inspired navigation, interactive elements, subtle animations, and sound design, it offers a distinctive way to explore my work.

> A portfolio that feels less like a website and more like an experience.
